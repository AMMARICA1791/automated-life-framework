# Contributing
Thank you for contributing! This is Observer-Only framework that prevents regret.
Core Philosophy: Not a tool that brings news faster, but a mirror that prevents regret slowly.
Golden Rule: Time is like a sword.

Two types:
1. Sword Decisions: Immediate action, human mind only
2. Building Decisions: Use framework - 4 lines template

How to Contribute:
1. Improve a Sage in prompts/
2. Keep it 4 lines only
3. Keep observer-only principle: user never touches Drive/GitHub manually
4. Keep all files in English

PR Process: Fork -> Branch feature/your-idea -> Test with 4-line example -> Submit PR
