# Security Policy
Supported Versions: 1.x ✅
Reporting: If you find issue related to sync scripts or secrets handling, report via GitHub Issues with label security. Do NOT open public issue with secret keys.
Secrets Handling:
* Never commit GDRIVE_KEY or GH_PAT
* Always use GitHub Secrets
* .gitignore blocks credential files
No Data Collection: Framework does not collect personal data. Observer-Only means your decisions stay in your Drive.
